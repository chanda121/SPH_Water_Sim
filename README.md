# Shallow Water Equations Simulation
---
Following the papers of Solenthaler et al (https://matthias-research.github.io/pages/publications/SPHShallow.pdf) and Lee and Han (https://link.springer.com/article/10.1007/s00371-010-0439-9) to simulate shallow water  

We use PySPH library to handle the time integration, particle array, and nearest neighbour particle search (NNPS)  
Currently, results are graphed to 2D heatmap graph,
